# INT144 Agile Study Room

ห้องอ่านสอบ Agile Software Development I รวมสรุปภาษาไทยครบ 5 บท คำอธิบายจาก transcript และคำศัพท์ 123 คำ

เปิดเว็บ: https://089-dusitt.github.io/int144-agile-study/

## ใช้งาน

- อ่านบทเรียนพร้อมคำศัพท์ข้างเนื้อหา
- กดคำเส้นประเพื่อเปิดความหมายและตัวอย่าง
- ค้นหาเนื้อหาและคำศัพท์ด้วย Ctrl+K
- ปรับขนาดตัวอักษรและโหมดสว่างหรือมืด
- จำบทล่าสุด ตำแหน่งอ่าน และความคืบหน้าในเบราว์เซอร์
- มีหน้าทวนก่อนสอบและคำถามเช็กความเข้าใจ

เวอร์ชันออนไลน์แสดงรายชื่อเอกสารอ้างอิง โดยไม่ได้แนบ PDF หรือ transcript ต้นฉบับ

## แก้ไขและเผยแพร่

เว็บเป็น HTML/CSS/JavaScript แบบ static ไม่ต้องติดตั้ง dependencies เนื้อหาอยู่ใน `dist/data.js` ตรวจด้วย `node check-site.mjs` การ push ไปยัง `main` จะตรวจเนื้อหาและเผยแพร่ผ่าน GitHub Pages อัตโนมัติ
